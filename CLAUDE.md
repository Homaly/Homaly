## What is being built

An entry for the Hackathon by Aveiro Tech City ("Let's Hack This City!"), Challenge #3 from Altice Labs: **"Connected Home, Reimagined: A IA ao serviço da casa"**.

Constraints taken from the brief:

- **The MCP server is mandatory.** Altice Labs provides an MCP (Model Context Protocol) server that exposes the devices installed in a connected home. It is the main technical resource of the challenge and must be integrated into the solution.
- **The MCP server's tools are not documented here.** The brief says a separate technical support document for the MCP server will be handed out. Until that document (or the server itself) is available, do not guess its endpoint, authentication, tool names or device list — ask for it.
- **The problem is deliberately open.** No predefined problem or application type. Suggested areas: automation, accessibility, energy efficiency, comfort, security, entertainment, communication, daily routines, or something unexpected.
- **Plain device control through AI is explicitly not the goal.** The brief asks to go "beyond commands": combine context, intent, information and action into something useful, surprising or innovative. Judge feature ideas against this, not against how many devices they can toggle.
- **Allowed technologies:** Mobile, Web, Cloud, AI — no specific stack is imposed.
